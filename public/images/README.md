# Imágenes de demostración

hero.jpg, jewelry.jpg, watch.jpg y fragrance.jpg fueron generadas para este proyecto como fotografía conceptual. No corresponden a inventario real ni verifican material, fabricante, autenticidad o calidad. Los nombres, precios y existencias de los seis artículos son ejemplos.

Sustituir estas referencias por fotografías reales autorizadas antes de venta. El catálogo puede compartir una referencia visual entre conceptos; no presentar esos conceptos como artículos disponibles. No hay fotografías descargadas de Unsplash: la descarga no fue autorizada por la red y no se utilizaron esos archivos.
